## 執行基準與記錄方式

開始前填寫：日期與操作者＿＿；測試的 Git HEAD＿＿；單人／dedicated server 與 client 數＿＿；測試世界或複本名稱＿＿；Minecraft／Fabric 與 render stack＿＿；證據目錄＿＿。每一項填 `PASS`／`FAIL`／`未執行`，附截圖、F3／唯讀讀值、對應 log 時間與偏差；沒有讀到的資訊留空，不用推測補齊。任何程式變更後，依 [AGENTS.md](../../AGENTS.md) 的門檻判定受影響項重驗。

先用獨立的新測試世界或 Chamber 做單人兩輪；DORMANT 只用外部備份 `QC-accept-WM4` 的**複本**，不碰備份原件與使用者正式世界。需要唯讀查收據或比對 journal 時，記下命令、時間與輸出檔，不改收據。測試過程不要用 `/tick freeze`，否則通道 60 秒也會停止計時。沒有正規回程；目的宇宙的死亡與原版傳送門屬非正規回程，不能當作本次通道成功或安全回程的驗收方式。
