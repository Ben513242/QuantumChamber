# QuantumChamber M1 Chamber Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可手動搭建、驗證、註冊、保護並以 QuantumState 加 vanilla redstone 啟動至 `ARMED` 的 7 × 7 × 7 Quantum Chamber，且不進入 Superposition 或任何跨世界流程。

**Architecture:** M1 將幾何、狀態判定與 rising-edge 邏輯保持為可純 JVM 測試的 domain units；Minecraft adapters 負責 blocks、players、PersistentState、redstone 與單一 `World#setBlockState` 保護閘門。Global Chamber Registry 與 ProjectionIndex 從第一版存在，但 M1 只建立 Origin instance，不建立或物化跨 Universe Projection。

**Tech Stack:** Minecraft 1.21、Yarn 1.21+build.9、Fabric Loader 0.17.2、Fabric API 0.102.0+1.21、Fabric Loom 1.7.4、Gradle Wrapper 8.8、Java 21、JUnit Jupiter 5.10.3、Fabric Loader JUnit、Fabric GameTest。

**Spec:** `docs/quantum_superposition_chamber_design.md`

## Global Constraints

- Minecraft 固定為 `1.21`，Yarn 固定為 `1.21+build.9`。
- Fabric Loader 固定為 `0.17.2`，Fabric API 固定為 `0.102.0+1.21`，Fabric Loom 固定為 `1.7.4`。
- Java 固定為 21，Gradle Wrapper 固定為 8.8。
- Mod ID 為 `quantumchamber`，Java package root 為 `dev.quantumchamber`。
- 維持單一 Fabric module 與 `splitEnvironmentSourceSets()`；所有 Chamber gameplay、Registry、Persistence、Protection 與 Redstone 程式都放在 `src/main/java`。
- M1 只能建立 Origin Chamber；資料型別可保留 `ORIGIN`／`PROJECTION` 區分，但不得物化 Projection。
- 保留同 `DimensionRole` 的全域 Chamber bounding-box 重疊拒絕規則；不同角色可使用相同 XYZ。
- 已註冊 Chamber 的 7 × 7 × 7 volume 必須受單一 server-authoritative mutation gate 保護；mod 自己的 bulkhead 操作需使用明確 authorization context。
- Chamber geometry 固定為外部 7 × 7 × 7、牆厚 1、內部 5 × 5 × 5、前牆中央 5 × 5 bulkhead、controller local position `(3,6,0)`。
- Controller `FACING` 指向 Chamber 外側；local `+z` 指向 Chamber 內部，local `+x` 使用 `FACING.rotateYCounterclockwise()`。
- `INVALID`、`IDLE`、`READY`、`ARMED` 的 comparator output 固定為 `0`、`3`、`7`、`11`；`15` 保留給未來 passage-ready，不得在 M1 使用。
- Redstone activation 使用 unpowered → powered 的 rising edge；持續 power 不得重複觸發，chunk load 時同步 latch 不得製造假 rising edge。
- M1 `READY → ARMED` 不建立 Session、不傳送玩家，也不消耗 QuantumState；效果消耗仍屬未來成功進入 Superposition 的原子轉換。
- QuantumState ID 與 Potion ID 均為 `quantumchamber:quantum_state`；duration 3600 ticks、amplifier 0；recipe 為 Awkward Potion + Echo Shard。
- 所有完整位於 interior 的非 spectator 玩家都是參與者；零參與者或任一參與者缺少 QuantumState 時不得進入 `ARMED`。
- M1 不得建立 `UniverseRegistry`、runtime dimension、dimension family、superposition dimension、corridor、candidate resolver、collapse、packet 或 teleport logic。
- 不得新增 Iris、Sodium、Immersive Portals、DimLib、Cloth Config、Mod Menu 或其他必要依賴。
- 不得新增 `LICENSE`；Repository 維持 Public、未授權再利用。
- 每個新增行為的 Task 都必須保留 RED／GREEN 證據；純 Minecraft framework wiring 與 JSON assets 以 compile/build/GameTest 驗證，不寫只比對原始碼文字的假測試。
- M1 完成前必須執行 `./gradlew clean build`、Fabric GameTests、client runtime、dedicated-server `Done → stop`，並寫入 `docs/implementation-notes/m1-chamber.md`。

`ChamberGeometry` 必須使用以下固定 contract：

```java
public static final int OUTER_SIZE = 7;
public static final int INTERIOR_SIZE = 5;
public static final BlockPos CONTROLLER_LOCAL_POS = new BlockPos(3, 6, 0);

public static BlockPos localToWorld(ChamberFrame frame, int x, int y, int z) {
    requireLocalCoordinate(x, y, z);
    Direction right = frame.outwardFacing().rotateYCounterclockwise();
    Direction inward = frame.outwardFacing().getOpposite();
    return frame.controllerPos()
            .offset(right, x - 3)
            .add(0, y - 6, 0)
            .offset(inward, z);
}
```

`DimensionRole.fromVanillaKey` 只接受 `World.OVERWORLD`、`World.NETHER`、`World.END`；其他 key 回傳 empty，M1 不猜 custom world role。
